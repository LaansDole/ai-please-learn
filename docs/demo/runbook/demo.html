AI, Please Learn (EvoLab): demo

One continuous recording of the live site in a fresh browser. You play Snake and crash, set the rewards, then watch NEAT and DQN learn it, a 3D stick figure learn to walk, and gpt-6-luna write a new game from one sentence that NEAT then trains. The header on the Learn step says whether a run is still learning or has stalled. Captions quote the numbers on screen. Idle stretches longer than 2.5 s are shortened. Nothing else is cut or staged.

Recorded 2026-11-22 on https://laansdole.github.io/ai-please-learn/ at commit 935c123 (Field guide redesign), fresh Chrome profile, OpenAI gpt-6-luna. Click any step in the list to jump there.

Run it yourself

# nothing to install: open the live site
open https://laansdole.github.io/ai-please-learn/

# or run it locally (git clone https://github.com/LaansDole/ai-please-learn)
npm install
npm run dev

Then follow the steps in the list above. For the Create step, open Settings, keep OpenAI selected and paste your own API key (it stays in your browser), or pick LM Studio or Ollama for a local model. Full instructions: runbook.
